Cloud architecture under real failure

Situation Windows Azure Storage was a global distributed file system, and Amazon needed book-page images served worldwide.

Task Improve the storage system, and build the image service.

Action He worked on Fast Multi-Paxos in Azure Storage and traced a memory corruption to a bit error after ruling out software causes, across a stated fleet of 500,000 compute nodes. At Amazon he designed a low-latency image service and an 80TB migration to S3.

Result The Azure failure rate matched the expected bit-error MTBF. Amazon delivery time fell 30% for 900,000 books.

AI inside a product, not a side project

Situation Kinect interaction was heuristic, and Quintar’s stereo video was not yet a spatial experience.

Action He designed the Kinect move from heuristics toward reinforcement learning while shipping the body-tracking API. He led Quintar’s AI transformation to an AI-native approach.

Result Kinect APIs shipped in Windows and Xbox. A more natural interaction cut test time 80%. The Quintar pipeline became a production effort for digital-twin viewing.

Augment, don't replace, construction workflows
